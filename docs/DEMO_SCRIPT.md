# Eventra — 90-second judge demo

## Before recording

- Open the production URL in a fresh browser window.
- Confirm the page title and header say `Eventra`.
- Use Eventra Core so the report does not depend on external model capacity.
- If a verified DreamDEX campaign exists, use Live mode. Otherwise use Test Arena and say explicitly that it is simulated.
- Keep one Somnia explorer tab ready with a deployed Eventra contract or a previously confirmed transaction.

## 0–12 seconds — problem and product

**Action:** Show the Eventra home and scroll to market discovery.

**Narration:** “DreamDEX gives traders live Event Contract odds. Eventra adds the missing decision layer: which campaign is usable, why the signal matters, and whether the trade should be executed at all.”

## 12–27 seconds — choose campaign

**Action:** Select one campaign.

**Narration:** “Eventra ranks campaigns using market availability, liquidity, expiry and live evidence. Today I am using [DreamDEX Live / the clearly labelled Test Arena because no verified testnet campaign is open].”

## 27–40 seconds — choose AI and fee

**Action:** Show the AI selector, choose Eventra Core, then show fee review.

**Narration:** “The user chooses the analyst. Every model has a visible analysis fee before generation; Eventra Core is the free transparent baseline. Paid reports use a Somnia escrow and are charged only on successful fulfillment.”

## 40–64 seconds — report

**Action:** Generate the report and pause on Quick Predict, key metrics, confidence, invalidation and deep research.

**Narration:** “The output is not a black-box prediction. Eventra separates the direction, confidence, market confirmation, technical evidence and invalidation conditions. WAIT is a valid outcome when execution evidence is weak.”

## 64–80 seconds — order control

**Action:** Show the chart and order ticket. Select UP or DOWN and change the amount. In Test Arena, place the simulation. In Live mode, stop before the final signature unless the campaign and collateral are verified.

**Narration:** “The report becomes an actionable order ticket, but the AI never trades autonomously. The user controls side, size and wallet confirmation.”

## 80–90 seconds — proof and close

**Action:** Show the resulting position/receipt and briefly open a Somnia explorer contract page.

**Narration:** “Eventra combines DreamDEX execution with Somnia-native policy, forecast proof and pay-on-success AI fees. It turns Event Contracts from a raw market into a complete decision product.”

## Recording rule

Never call a Test Arena action an on-chain trade. Never imply that an old explorer transaction belongs to the campaign currently visible on screen.
